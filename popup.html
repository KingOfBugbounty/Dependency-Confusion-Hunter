ℹ️ Detection & Severity Guide

Confidence Levels:

High (≥90%): Packages found in package.json, lock files, or with typical npm naming patterns.

Medium (70-89%): Packages extracted from require() or import with valid names.

Low (<70%): May be false positive - verify manually.

Severity Levels:

Critical: CI/CD environment + secrets detected

High: CI/CD environment OR root user

Medium: Local development machine
